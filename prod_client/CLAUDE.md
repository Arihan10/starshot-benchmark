SceneBench
SceneBench is created by Starshot Labs, which created multi-object 3D scene diffusion, a novel way to diffuse over an entire 3D area with the generation of discrete 3D objects as opposed to existing diffusion models that can only create a single 3D object. LLMs can be used to orchestrate the placement/styles of many canvases that use multi-object scene diffusion in order to go from a single text prompt to an entire, high-fidelity, cohesive 3D scene composed of individual, game-ready objects, and SceneBench is a platform that allows users to compare the 3D scene generations between different LLMs, similar to a platform called https://minebench.ai/. 

SceneBench is a tech demo disguised as a very cool and novel game (the appeal isn't any "gameplay" but the wow/cool factor of seeing these very high-fidelity 3D scenes, and the simple mechanic of picking the better scene . As such, the platform (which is currently only one page) is very minimal and sleek in design.

General principles:
Generic cards/components repurposed for different uses by replacing text is BAD, "card" design is disliked
Everything should be very BOLD and CLEAN - very "sharp" design, with NO gradients or components that have a slightly altered (e.g darker/brighter) background color within them and a bright border around the component (lined borders around buttons and all are typically disliked)
The page and components should have a very geometric, distinct design
Big, primitive parts are disliked
Very responsive, fluid, concentrated, and most importantly, smooth animations
There should be visual hierarchy - not a bunch of same size/style components separated by borders, but distinct, intrinsic geometric hierarchy
Subtle texture/effects can be used to mitigate primitiveness of the geometric shapes
No vibe coded bullshit clutter of unasked text metadata all over the page - everything should be very tightly and cleanly scoped
Maximize functionality - e.g most of the page (optimized for maximum vertical/horizontal length) should be the two 3D scenes side-by-side for comparison, presented automatically
Really SNAPPY and smooth but cool 2D/3D animations for everything - focus on fluid and responsive

Overall, this represents the launch for Starshot Labs as a company and the site should look like it comes from a new Frontier Lab. REMEMBER - the design should NOT look game-y or like a game itself, it should look like a sleek, frontier, clean tech demo
