when coming up with the list of objects, be aware that a downstream step is responsible for outputting an AABB for each object you output, and another downstream step is responsible for generating the actual 3D meshes based on each object's prompt. the 3d mesh generator excels at generating individual, atomic objects - it is NOT reliable when it comes to collections of objects placed in a certain shape or manner and will often have devastating results on the entire scene, especially since the output mesh gets stretched and scaled to the bounding box given for it. as such, ignore intangible objects like gasses, and ALWAYS split groups of objects into individual ones, then use the placement text and relationships list to convey the meaning of how they should be placed in the scene so each individual object in the collection gets its own mesh and bounding box.
